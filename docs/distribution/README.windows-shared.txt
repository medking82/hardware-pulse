Hardware Pulse for Windows x64

This package uses the shared App and Desktop components with a dedicated Windows
hardware collector. Windows 10 22H2 / Windows 11 x64 and .NET Framework 4.8 are
required. The App's modern .NET runtime is bundled. The installer manages the
collector and PawnIO prerequisite; do not copy individual files over an install.

A version containing -rc or -preview is a prerelease, not a stable release.
Stable installed builds import recognized 0.6.27 preferences without rewriting
the original profile. Development/prerelease builds use the separate preview
profile. Quota access is opt-in and depends on provider login availability.

Close hides the App when its tray is available. Use the tray to reopen or Quit.
If setup reports an incomplete installation, retain the setup log, resolve the
reported prerequisite/startup error and rerun setup. A post-install failure may
leave updated files; it is not a guarantee that the old installation was restored.

See PRIVACY.md, SIGNING.md and licenses for data, signing and dependency details.
