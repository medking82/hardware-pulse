# UI Acceptance

[简体中文](UI-STYLE.zh-CN.md)

- Use Title Case for every word in English headings, labels, choices and buttons, including `Save Encrypted`, `Topped Up` and `5-Hour`. Preserve official brand spelling, acronyms, units, endpoints, user-defined names and persisted/protocol identifiers. Explanatory sentences are not captions; never change source data for capitalization.
- Keep compact readings concise: the desktop balance title is `DeepSeek`, and the card caption is `Balance`. Put the detailed description in the tooltip.
- Local inference uses a stable `localModelSpeed` visibility/order key after quota rows, a source-catalog icon and lowercase `tok/s`. Strata keeps all three SVG layers and the existing theme/palette priorities. Only current generation occupies the numeric cell; prefill, idle, unloaded, unavailable and stale states must not become zero or retain a previous request's live value. History is explicitly labeled Last Request, not attributed to the current model. A local-inference-only monitor is not empty.
- DeepSeek currency display is a persisted CNY (RMB), USD or All choice shared by App and Desktop. Filter original balances without conversion, fabricated amounts or substitution of another currency for a selected zero balance.
- New AI/local-inference App cards must reuse the existing translucent surface, padding, corners, title/icon scale and responsive card columns, not append a separate full-width banner. Connect the normal drag handle, keyboard reorder, cancel, position lock and persisted order; polling must not rebuild a card during dragging. Keep nonnumeric states compact and long telemetry explanations in tooltips. Verify the card beside existing cards, not only in an isolated single-card screenshot.
- DeepSeek desktop visibility and order use the stable `quotaDeepSeek` group. All its currency and error/status rows follow that group. Currency changes must not move the group or expose hidden rows. Desktop visibility does not disable monitoring or the App card.
- Verify actual WPF settings, cards and narrow desktop readings in English and Simplified Chinese, in light and dark themes. Run `scripts/Test-QuotaFeature.ps1 -AppPath <isolated-built-app>` with synthetic fixtures. Compilation or a main-window screenshot alone does not verify desktop-row layout.
- Argon is an independent weekly pool under the existing Antigravity source, not a new provider/login. Use `Argon · Weekly` on Desktop and an Argon subsection in the App. Preserve its own reset time and true zero; never borrow a Gemini five-hour window or combine percentages. Stable window identity must preserve ordering/visibility, including an upgrade from a fully hidden Gemini group.
- Manual Refresh is an explicit forced request, as shipped in 0.6.65. Disable it while a request is in flight, without queuing repeated clicks. Automatic polling retains its cadence, Retry-After and failure backoff; do not restore the former cooldown-disabled manual button. Validate both paths with `scripts/Test-Core.ps1` and the native quota feedback tests.
- Settings must preserve an unreadable profile instead of overwriting it with defaults, show pending/saved/failed status, and keep diagnostic IO failures outside the UI event loop. Settings categories support Left/Right/Home/End, and sliders show keyboard focus in both themes.
- A sharing-conflict fallback may show only a validated sample still inside the original fifteen-second freshness limit, with its original timestamp and an explicit Recent Sample / Retrying Snapshot warning in App and Desktop. Missing, denied, malformed or expired snapshots must not keep old live values. Distinguish the read failure from an assumed collector exit.
